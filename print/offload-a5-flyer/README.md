# Offload Waste Removal – A5 door-drop flyer

**Print file:** `Offload-A5-Flyer-PRINT-bleed.pdf` (2 pages: front, back)

| Spec | Value |
|---|---|
| Finished (trim) size | A5, 148 × 210 mm |
| Bleed | 3 mm each side (PDF page = 154 × 216 mm, TrimBox set) |
| Safe area | 5 mm inside trim |
| Colour | RGB – ask the printer to convert to CMYK (neon lime will print slightly duller) |
| Fonts | Anton, Barlow, Barlow Condensed (embedded) |
| Suggested stock | 350–400 gsm silk, or 170 gsm gloss for a cheaper door drop |

**Front:** headline, 3-step "Snap it / Send it / Sorted" process, WhatsApp call to action with QR code, trust strip.
**Back:** services, coverage map, why choose us, duty-of-care warning, contact details and QR code.

The QR code opens WhatsApp chat with 07777 365390 with a pre-filled message.

## Check before printing
- Coverage area (Leeds + about 20 miles) and town list are assumed – confirm them.
- "Free quote", "Same-day collections*" and the list of services are taken from existing artwork – confirm they are still accurate.
- Scan the QR code on a proof.

## Rebuild
```
cd source && npm install && node build.js out
```
